# Project Brief — Pacman for Omarchy

The living context the loop steers by. `/ag-shape`, `/ag-spec`, `/ag-prioritise`,
and the `ag-planner` read this; Business Value in triage is scored against the
**prioritised outcomes** below. Keep it short (it loads into context) and update
it as the project learns — `/ag-retro` treats it as an update target.

## Who it's for

Keith, on his Omarchy desktops. A quick game to open for a few minutes that
feels like it belongs to the desktop: it wears the current Omarchy theme and
changes with it. Later, other Omarchy users via the plugin catalogue.

## The outcome that matters first

A playable Pac-Man round — maze, pellets, four ghosts, lives — running in its
own window from `bin/pacman`, drawn in pixel art that mimics the original
arcade look, coloured from the live Omarchy theme.

## Prioritised outcomes

1. Playable core game: maze, movement, ghosts with classic behaviour, lives, levels.
2. Looks beautiful and Omarchy-native: every colour comes from the active theme
   (`~/.local/state/omarchy/current/theme/colors.toml`) and recolours live on theme change.
3. Old-school feel: the original big-pixel look (drawn at 224×248, upscaled with
   hard pixel edges), arcade font, chiptune sound.
4. Installable as an Omarchy plugin: menu entry, desktop file, dotfiles submodule.

## Constraints

- **Stack:** QML on a standalone Quickshell process (`qs -p <repo root>`, a root
  `shell.qml` instantiating `app/Main.qml`), not inside `omarchy-shell` — see
  ADR-0001. Game logic in plain ES modules (`lib/*.mjs`) so `node --test`
  covers it and QML imports the same files.
- **Rendering:** one `Canvas` renderer in native 224×248 units inside a `PixelStage`
  component; arcade mode = low-res layer with nearest-neighbour integer upscale
  (the only mode in the game; PixelStage keeps a smooth fit for reuse) — see
  ADR-0002. `FrameAnimation` drives a fixed-timestep loop.
- **Sound:** QtMultimedia `SoundEffect` playing WAVs generated by a Python script
  (numpy + stdlib `wave`) committed under `assets/sfx/`. No external audio daemon.
- **Theme:** read `colors.toml` directly (the shell's `Color` singleton only exposes
  five roles). Never hard-code a colour.
- **Font:** vendor an OFL pixel font (Press Start 2P) under `assets/fonts/`; no
  system pixel font exists on Omarchy.
- **Runs standalone**, not as a bar widget. Tiled or floating is the compositor's
  call; the game scales to whatever window it gets.
- Personal project; original maze layout in the classic proportions (28×31 tiles),
  not a copy of the Namco maze.

## Non-goals

- No bar widget, no in-shell panel, no network features, no leaderboards beyond a
  local high score.
- No fruit bonuses, cutscenes, gamepad or two-player in v1 (captured in the inbox).
- No packaging for AUR or the public catalogue until the game is fun.

## What "shipped v1" looks like

`omarchy-menu` → Pacman opens a window. Title screen in the theme's colours;
Enter starts; arrows/hjkl/WASD move; four ghosts scatter, chase and flee;
power pellets, ghost eating, death, three lives, level clear and speed-up;
waka/siren/death sounds with a mute key; switching the Omarchy theme
recolours the running game; high score survives restarts.
